Methods, benchmark checks and source data

Evaluation integrity. The scaler and logistic regression were fitted on training embeddings only. The independent evaluation set was not used for model or threshold selection. Original multiclass predictions use argmax across nine probabilities; the separate tumour decision uses p_TUM. This explains why TUM recall in the chart can differ from the thresholded sensitivity.

Fixed benchmarks. Review cutoff 0.80, tumour threshold 0.50, high confidence 0.90. Changes to the controls are exploratory and do not establish an optimal clinical operating point. The metric checks below always use the frozen defaults.
